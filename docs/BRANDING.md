# localforge — Branding

## Name & Tagline
**localforge** — *"Forge LLMs on the hardware you have."*
Lineage with prior course projects (`article_forge`, `graphquest`): "forge" = craft/measure locally; "local" = the core thesis (run giant models on modest, even CPU-only, machines).

## Positioning
A teaching-grade, reproducible benchmark + fine-tuning + visualization toolkit that makes the *cost* of local LLM execution visible — especially AirLLM's OS-style paging.

## Voice
Precise, measurement-driven, honest about limits (CPU-first, skips not crashes). Engineering-report tone, not marketing.

## Visual / CLI identity
- Accent: deep indigo + ember-orange ("forge").
- CLI: Rich tables with an ember header rule; the Paging Visualizer uses a cool→warm gradient mapping the memory hierarchy (cold disk → hot registers).
- Logo motif: an anvil over a memory-ladder bar.

## Artifacts that carry the brand
`report.html` header, the paging-timeline PNG/HTML, and README hero (comparison table + paging figure).
